# 🎵 AMPLIFY MUSIC

A sleek, dark-themed HTML/CSS web music player interface created to give users an immersive audio experience with custom visuals.

---

## ✨ Features

* **Custom UI Theme:** Deep space dark gradient background with vibrant purple and cyan accents.
* **Audio Visualizer Header:** Background video setup to provide a visualizer feel.
* **Music Tracks:** Multi-track selection featuring popular hits.
* **HTML5 Media Controls:** Built-in audio controls for play, pause, and volume management.
* **Creator Branding:** Personal badge/profile section integrated into the layout.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup, Video & Audio media APIs.
* **CSS3:** Inline styling, CSS Gradients, Flexbox, and absolute positioning.
